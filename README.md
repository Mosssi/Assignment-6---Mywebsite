# FG -- Building My First Website

My first personal portfolio website, built while studying Frontend Development at FutureGames (FG). This project was my introduction to structuring a real webpage with HTML, styling it with CSS, and adding interactivity with vanilla JavaScript.

🔗 **Live site:** https://mosssi.github.io/FG--BuildingMyFirstwebsite/

## About the Project

This is a single-page portfolio with a linked project showcase page. It introduces me, lists my current skills, shows my education timeline, links out to a project page, and includes a contact form.

### Sections

- **Home** — intro with an animated typing effect (`Frontend Developer / Tech Enthusiast / UI/UX`)
- **Skills** — a grid of the tools and languages I'm learning: HTML5, CSS3, JavaScript, React, Tailwind CSS, Git, Figma, VS Code
- **Experience & Education** — a timeline entry for my studies at FutureGames
- **Project** — a separate page (`project.html`) showcasing project work
- **Contact** — a simple form for getting in touch

## Built With

- HTML5 & CSS3
- Vanilla JavaScript
- [Typed.js](https://github.com/mattboldt/typed.js/) — the typing animation in the hero section
- [Particles.js](https://vincentgarreau.com/particles.js/) — background particle effect
- [Font Awesome](https://fontawesome.com/) & [Devicon](https://devicon.dev/) — icons

## Project Structure

```
├── index.html      # Main landing page
├── project.html    # Project showcase page
├── style.css       # Styling
├── script.js       # Interactivity
└── images/         # Site images and icons
```

## Running Locally

No build step needed — it's a static site.

1. Clone the repo
   ```bash
   git clone https://github.com/Mosssi/FG--BuildingMyFirstwebsite.git
   ```
2. Open `index.html` in your browser (or serve the folder with any static server / Live Server extension)
